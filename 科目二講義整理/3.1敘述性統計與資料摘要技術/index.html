敘述性統計與資料摘要技術

用少量統計量與圖表回答三個基本問題：資料中心在哪裡、分散多大、分佈長什麼樣子，為後續推論、特徵工程與模型設計奠定基礎。

01｜敘述性統計的三大面向

官方 P. 3-2～3-3

敘述性統計著重「直接總結與呈現現有資料」，不負責從樣本推論整個母體。它讓分析者在建模前快速掌握全貌、辨識異常與選擇適當的後續方法。

01

集中趨勢

平均數、中位數、眾數等，用來描述資料最典型或核心的位置。

02

離散程度

變異數、標準差、全距、IQR，用來描述波動與資料分散程度。

03

分佈形狀

偏度、峰度、直方圖與箱形圖，用來觀察對稱性、長尾與極端值。

先描述，再推論

資料 → 摘要統計與視覺化 → 發現模式／問題 → 前處理與建模

本節是 EDA 的基礎；3.2 才進入機率分佈，3.3 才進入假設檢定與統計推論。

02｜集中趨勢：平均、中位數、眾數

官方 P. 3-3～3-5
指標意義適合情境限制
算術平均全部數值加總後除以筆數。資料大致對稱、沒有強烈極端值；平均銷售額、平均重量。容易被離群值拉高或拉低。
中位數排序後位於中央的值。收入、房價等偏態或有極端值的資料。不能單獨描述分散程度。
眾數出現次數最多的值或類別。產品類別、尺寸、顏色等類別型資料。可能沒有唯一眾數；連續資料常需分箱。

對稱資料

平均數與中位數通常接近，可用平均數搭配標準差描述。

右偏資料

少數大值會拉高平均數，常見關係是平均數 ＞ 中位數；代表典型個體時中位數較穩健。

03｜算術、幾何與調和平均

官方 P. 3-3～3-5
平均方式公式與直覺典型用途必要條件／提醒
算術平均 AMx̄ = Σxᵢ ÷ n；總量平均分配。加總型數據、一般水準比較。極端值影響大。
幾何平均 GMGM = (∏xᵢ)^(1/n)；連乘後的等效平均。成長率、投資報酬、人口成長等乘積效應。講義脈絡要求數值皆為正；不適合含 0 或負值。
調和平均 HMHM = n ÷ Σ(1/xᵢ)；先取倒數再平均。速度、速率、效率與「每單位」型資料。不可含 0；應確認分母條件一致。

快速辨識

一般加總 → 算術平均｜連續乘積／成長 → 幾何平均｜速率／效率 → 調和平均

例如同距離往返速度不可直接做算術平均，因為每段耗時不同；此時調和平均更合理。

04｜離散程度：波動有多大？

官方 P. 3-6～3-7
指標計算／意義優勢限制
變異數與平均數差距的平方平均；母體形式為 σ² = Σ(xᵢ-μ)²／N。量化整體波動，是許多統計模型的基礎。單位是原單位平方；極端值影響大。
標準差變異數平方根 σ = √σ²。單位與原資料相同，容易解讀。偏態或離群值多時需搭配 IQR。
全距最大值 - 最小值。最快速了解整體跨度。只看兩個端點，極易受單一極端值影響。
四分位距 IQRQ3 - Q1，描述中間 50% 資料範圍。對離群值較穩健，適合偏態資料。不呈現尾端與分佈全部細節。

記憶口訣

變異先平方，標準再開根。變異數方便計算；標準差回到原資料單位，方便直接解讀。

數字例子

若變異數是 25 分²，標準差就是 √25＝5 分，可解讀為成績通常離平均數約 5 分。

快速分辨

變異數＝平方單位；標準差＝原始單位

兩者都不會小於 0；等於 0 代表所有觀測值完全相同。偏態或離群值很多時，應搭配中位數與 IQR。

iSpan 補充 與機器學習的連結

不同特徵的標準差與尺度差異很大時，可能需要 Standardization，避免距離或梯度被大尺度特徵主導。

05｜四分位數與箱形圖

官方 P. 3-7～3-10
Q1

第一四分位數

25% 的資料位於此值以下；也是箱子的下邊界。

Q2

第二四分位數

即中位數；50% 資料在其下、50% 在其上。

Q3

第三四分位數

75% 的資料位於此值以下；也是箱子的上邊界。

箱形圖元件如何解讀常見考點
盒子從 Q1 到 Q3，涵蓋中間 50% 資料。盒子越長表示中段資料越分散。
中位線盒內的 Q2 位置。偏向盒子一側，可能顯示分佈不對稱。
鬚 Whiskers延伸到仍在正常界線內的最遠觀測值。上鬚不必等於全資料最大值，下鬚也不必等於最小值。
離群值常指低於 Q1-1.5×IQR 或高於 Q3+1.5×IQR 的值。先標示與調查，不等於一定要刪除。

IQR 離群界線

下界 = Q1 - 1.5 × IQR｜上界 = Q3 + 1.5 × IQR

鬚通常畫到界線內最遠的實際觀測值；界線本身不一定就是鬚端的資料值。

06｜偏度與峰度

官方 P. 3-10～3-12

6.1 偏度 Skewness：尾巴朝哪邊？

形狀數值與方向典型關係／案例
正偏／右偏Skewness ＞ 0；右側尾巴較長，主體在左。收入、房價、故障時間；大值拉高平均，常見 Mean ＞ Median。
負偏／左偏Skewness ＜ 0；左側尾巴較長，主體在右。大量高分但少數低分；小值拉低平均，常見 Mean ＜ Median。
近似對稱Skewness ≈ 0。平均數與中位數通常相近，但不代表一定是常態。

偏度記法

尾巴指方向；平均數跟尾走

右尾長＝正偏，少數大值把平均數往右拉；左尾長＝負偏，少數小值把平均數往左拉。方向不是看山峰在哪一邊。

6.2 峰度 Kurtosis：尾部有多厚？

Pearson 峰度名稱特徵風險意義
＞ 3高峰 Leptokurtic中心較集中、尾部較厚、極端值機會較高。外推、風險分析與異常偵測需特別注意。
≈ 3中峰 Mesokurtic接近常態分佈，作為比較基準。尾部程度接近常態。
＜ 3扁平 Platykurtic分佈較平坦、尾部較輕。極端值機會相對較低。

「尾巴厚」是什麼？

不是圖線畫得比較粗，而是離平均數非常遠的資料，比常態分佈更常出現。例如多數成績約 70 分，卻偶爾出現 20 或 100 分。

兩種峰度基準

Pearson 峰度以常態＝3；超額峰度以常態＝0。題目若未說明，要先確認使用哪一種定義。

偏度與峰度不要混淆

偏度管左右；峰度管厚尾與極端值

高峰度的重點不是只有峰頂較尖，而是極端事件的機率較高。

iSpan 補充 偏態過大時

可評估 Log Transformation 或 Box-Cox Transformation，以改善資料分佈與模型穩定性；但轉換前應確認資料範圍及解釋方式。

07｜統計摘要如何支援建模

iSpan 應用補充
原始資料尚未掌握品質與形狀
摘要統計中心、變異、偏態、峰度
視覺檢查Histogram、Box Plot、QQ Plot
品質判斷缺失、離群、尺度與分佈
前處理標準化、轉換、異常處理
特徵篩選保留可靠且有意義的變數
模型訓練評估與持續修正
工具最適合觀察看不到或要留意
直方圖 Histogram整體形狀、偏態、多峰、空洞與分箱後頻數。結果會受分箱寬度影響。
箱形圖 Box Plot中位數、IQR、偏態線索、異常值及群組比較。無法清楚呈現多峰等細節。
QQ Plot樣本分位數是否接近理論分佈，例如常態。需判讀點是否沿參考線，尾端偏離代表厚尾或極端值。

08｜易混淆辨析與考題線索

整合複習
主題常見誤判正確辨析
敘述統計 vs 推論統計看到平均數就能推論全體母體。敘述統計只摘要現有資料；母體推論需抽樣理論、估計或檢定。
平均數 vs 中位數平均數永遠最能代表典型值。偏態或離群值明顯時，中位數通常更穩健。
變異數 vs 標準差兩者單位與原資料都相同。變異數是平方單位；標準差才與原資料同單位。
全距 vs IQRIQR 是最大值減最小值。Range = Max-Min；IQR = Q3-Q1。
箱形圖鬚端鬚一定等於全體最大值與最小值。鬚通常是 1.5×IQR 界線內的最遠資料；超出者另標為離群值。
右偏方向資料主體在右，所以叫右偏。偏態由長尾方向命名；右偏是右尾長、主體多在左。
峰度只描述峰頂高度。更重要的是尾部厚度與極端值機率；本講義採 Pearson 常態基準 3。

箱形圖題型

盒子短＝中間 50% 集中；鬚長＝尾端延伸。離群值多寡仍要看鬚外獨立點，不能只看鬚長。

補值題型

平均數遠高於中位數且最大值極大，通常顯示右偏；少量缺失值若要降低極端值影響，可優先評估中位數補值。

F1-score 題型

F1 是 Precision 與 Recall 的調和平均，會受較小者明顯限制，不是普通算術平均。

標準化題型

Z-score = -2 表示觀測值低於平均數 2 個標準差；負號代表方向，不代表落在分佈之外。
